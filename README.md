# Intune---RemoveUpn
Remove UPN on Intune Devices in Bulk

These PowerShell scripts allow bulk management of User Principal Names (UPNs) associated with devices in Microsoft Intune. They use the Microsoft Graph API to either remove or restore user associations on managed devices. The scripts ensure smooth and automated management while keeping a log of actions performed.
1. Intune Device UPN Removal Script
Description:

This script removes the User Principal Name (UPN) from managed devices in Microsoft Intune. It connects to Microsoft Graph using credentials stored in a CSV file and logs all actions performed. It also saves a backup of removed UPNs in a CSV file, allowing future restoration.
Functionality:

    Reads connection parameters (ClientId, TenantId, CertificateThumbprint) from a CSV file.
    Connects to Microsoft Graph using the provided credentials.
    Retrieves a list of managed devices with an associated UPN.
    Removes the user association from each device using a DELETE request to the Graph API.
    Logs all actions and errors in a text file.
    Saves removed UPNs in a CSV backup file.
    Disconnects from Microsoft Graph when the process is completed.

Prerequisites:

    Microsoft Graph PowerShell SDK: Ensure it is installed (Install-Module Microsoft.Graph).
    Graph API Permissions: The script requires permissions to manage Intune devices (DeviceManagementManagedDevices.ReadWrite.All).
    CSV File with Connection Parameters:
        Create a file named connection_params.csv in the same folder as the script.
        Format:

        ClientId,TenantId,CertificateThumbprint
        your-client-id,your-tenant-id,your-cert-thumbprint

Output Files:

    Log File (removeUPN_log.txt): Contains logs of successful and failed operations.
    Backup File (removeUPN_backup.csv): Stores removed UPNs for later restoration.

2. Intune Device UPN Restoration Script
Description:

This script restores previously removed User Principal Names (UPNs) back to their respective devices in Microsoft Intune. It reads user-device associations from a CSV backup file and reassigns users using Microsoft Graph API.
Functionality:

    Reads the list of removed users from removeUPN_backup.csv.
    Connects to Microsoft Graph using the same credentials as the removal script.
    Queries Azure AD for the user’s GUID based on the UPN.
    Reassigns the user to the device using a POST request to the Graph API.
    Logs all actions, including successful reassignments and errors.
    Disconnects from Microsoft Graph when finished.

Prerequisites:

    Microsoft Graph PowerShell SDK: Must be installed.
    Graph API Permissions: Requires DeviceManagementManagedDevices.ReadWrite.All to modify device-user relationships.
    CSV Backup File (removeUPN_backup.csv): This file is generated by the removal script and is required for restoration.

Output Files:

    Log File (restoreUPN_log.txt): Stores logs of restoration attempts.
    Console Output: Displays the status of each restoration attempt.

Usage Notes

    Run the UPN Removal Script to remove user associations while storing backup data.
    Use the UPN Restoration Script to reassign users if needed.
    Ensure the correct permissions and CSV files are in place before executing the scripts.

These scripts provide an efficient way to manage UPN assignments in Microsoft Intune, ensuring smooth operations and easy recovery when needed.
